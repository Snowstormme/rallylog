# Tennis dataset attribution

The `data/sample_matches.json`, `data/sample_players.json` and `data/catalog_2023_2026.json.gz` files are selected records from tennis datasets compiled by **Jeff Sackmann / Tennis Abstract** and preserved by the [tennis-sackmann-archive](https://github.com/Aneeshers/tennis-sackmann-archive). The archive states that these data are licensed under [Creative Commons Attribution-NonCommercial-ShareAlike 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). These data retain that license. Do not use or redistribute them commercially.

The optional `flask --app wsgi import-tennis` command downloads more records from the same archive. Users of those records must retain attribution and follow the dataset license. The site's About page and footer display attribution.

Rallylog application code is separate from the imported tennis data.
