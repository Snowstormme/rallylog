# Security policy

## Supported version

Security fixes are applied to the current `main` branch and the production deployment built from it.

## Report a vulnerability

Please do not open a public issue with exploit details, credentials, personal data or database contents. Use GitHub's **Report a vulnerability** form in the repository Security tab when private vulnerability reporting is enabled. After launch, you can also use the contact address published on Rallylog's Privacy page.

Include the affected page, the expected and observed behavior, reproduction steps, and the minimum evidence needed to confirm the issue. Remove real user data and secrets from screenshots or logs.

The maintainer will acknowledge a report, assess its impact, prepare a fix, and coordinate disclosure after affected deployments are updated.
